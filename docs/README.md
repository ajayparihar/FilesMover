# FilesMover Documentation

This directory contains the documentation for the FilesMover project.

## Project Structure

The project is organized as follows:

```
FilesMover/
├── docs/                 # Documentation
├── examples/             # Example configurations and usage
├── scripts/              # Utility scripts
├── src/                  # Source code
│   └── files_mover/      # Main package
│       ├── cli/          # Command-line interface
│       ├── core/         # Core functionality
│       ├── gui/          # Graphical user interface
│       └── utils/        # Utility functions
├── tests/                # Test suite
├── LICENSE               # License file
├── README.md             # Project overview
├── run.bat               # Windows launcher
├── run.py                # Python launcher
└── setup.py              # Installation script
```

## Additional Versions

The project also includes:

- `simple_version/`: A simplified standalone version
- `batch_version/`: A batch script implementation

## Getting Started

Please refer to the main README.md in the project root for installation and usage instructions.
